## Implemented scope

The selected Re-Wired MNA solver is extracted into a game-independent Java core with actual logging and persistence interfaces. The audited RHS current-accumulation and QR fixes are retained. A real CompoundTag adapter connects component persistence to the modern API.

A single registered block, `eln:circuit_bench`, runs a bounded internal 10 V / 10 ohm / 1 F RC circuit at 0.05 s per simulation tick using that inherited solver. It supports server ticking, charge/discharge switching, V/A/J readouts, reset, versioned NBT validation, preserved unsupported/corrupted state, sanitized vanilla block-entity synchronization, and lifecycle cleanup. One recipe, loot table, creative tab and adapted original OBJ/PNG artwork are present.

There are no externally connected cable networks or complete legacy machines yet. The bench is an integration fixture, not the fully ported historical voltage-source device. Breaking/replacing it resets its charge. This is not full survival/content parity or legacy-world compatibility.

## Limits and next work

GameTests cover server ticks, numerical behavior, NBT object round-trip, malformed/future data, lifecycle callbacks, recipe presence, a real component NBT adapter and vanilla packet encode/decode. They do not establish an ordinary populated-world disk restart, actual chunk unload/reload, two-client interaction, human visual quality, external automation, modpack compatibility, Windows/Modrinth installation or large-network performance. The packaged client uses the real JAR through an isolated ModDevGradle/NeoForge launch, not a launcher installation test.

Next implementation: a per-level connected circuit manager plus source, resistive cable, load and capacitor, with analytical and chunk/split/merge tests. Then SixNode interaction, complete machine slices, thermal/mechanical systems, upstream parity, survival data and supported integrations.

Source model/code attribution and licensing remain in the modern module. No assertion is made that the previous 1.12 audit's inventory/network/save changes were all ported; only the selected core changes are included here.
